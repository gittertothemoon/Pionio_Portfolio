# Morning Image · 2 LUG

## Prompt AI (ChatGPT / Nano Banana / DALL-E)

```
Editorial macro photograph of three small smooth river stones aligned in a row on dark forest-green felt, soft cool light from above, slight shadow gradient on the right. Equal spacing between each stone, deep depth and museum-grade texture. Shallow depth of field. Pure black surrounding void on the edges. Mood: three as a deliberate composition, balance through repetition. Style: editorial still life photography, restrained palette. Avoid: text, people, faces, modern objects, neon, oversaturation.
```

## Pipeline

1. Genera 3-4 varianti
2. Salva PNG in `assets/morning-raw.png`
3. `cd src && node render.cjs`
